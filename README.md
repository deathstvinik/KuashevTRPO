## Практическая работа №2: CSS, адаптивная верстка и SCSS. Организация стилей
- **Расположение:** файлы находятся в папке второй практической работы (`catalog.html`, папки `scss/`, `css/`, `dataset/`)
- **Описание:** Адаптивный каталог учебных материалов с панелью фильтров и сеткой карточек (12 товаров из `catalog.csv`). Цветовая палитра, отступы и радиусы скругления вынесены в SCSS-переменные на основе `theme.json`.

### Архитектура SCSS
Стили разбиты на логические части (partial-файлы с префиксом `_`):
1. `_variables.scss` — переменные цветов, шрифтов и отступов (из `theme.json`).
2. `_base.scss` — базовые сбросы стилей, типографика и сетка контейнера.
3. `_layout.scss` — сетка каталога на CSS Grid и панель фильтров с медиазапросами для адаптива.
4. `_components.scss` — компоненты карточек товаров, кнопок, миксины и интерактивные состояния (`:hover`, `:focus`).
5. `styles.scss` — главный файл сборки, объединяющий все модули.

### Инструкция по сборке и запуску (SCSS -> CSS)
Для компиляции препроцессора SCSS в рабочий файл `css/styles.css`:
- **Через расширение Live Sass Compiler в VS Code:** включите режим *Watch Sass*. Изменения в папке `scss` будут автоматически компилироваться в `css/styles.css`.
- **Через терминал (npm / npx):**
  ```bash
  npx sass scss/styles.scss css/styles.css
