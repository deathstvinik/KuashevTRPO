# Практическая работа №1

Информационный портал учебного курса по дисциплине ТРПО.

## Локальный запуск
1. Склонируйте репозиторий.
2. Откройте `index.html` в браузере.

## Реализованные требования
- Использованы файлы `content.csv` и `navigation.json`.
- Семантическая разметка (header, nav, main, section, article, footer).
- Адаптивная верстка на Flexbox и Media Queries (мобильная адаптация до 720px).
